# 控制棒矩阵 · CORE//07

一个可离线运行的 3D 核反应堆控制棒阵列网页。976 根控制棒会随音乐的低频、中频和高频上下跳动，环形警示灯、堆芯辉光与遥测面板同步响应。

> 艺术可视化，不是工程仿真或真实反应堆控制界面。

## 两个版本

| 版本 | 启动方式 | 音频来源 |
| --- | --- | --- |
| 网页版 | 双击 `控制棒矩阵.html` | 本地文件 / 麦克风 / 浏览器屏幕共享音频 |
| 桌面版 | 双击桌面上的 `CORE07.exe`，或使用本目录的桌面版快捷方式 | 本地文件 / 麦克风 / **直接选择系统声音或某一程序声音** |

桌面版是 Windows x64 便携程序，内置 Web Audio 分析面板和 WASAPI loopback 音频捕获，无需安装、无需共享屏幕。详细说明见 `../desktop/README.md`。

> 本项目所在的 `Desktops\大肥鱼吃饭的地方` 目录受当前会话的执行策略限制，部分外部程序无法直接在该目录内启动。因此最终 EXE 已放置在 **`C:\Users\Administrator\Desktop\CORE07.exe`**，并在项目目录创建了快捷方式。把 `CORE07.exe` 拷贝到普通文件夹也可以正常启动。

## 网页版打开方式

直接双击 **`控制棒矩阵.html`**（或 `index.html`）即可。

- 无需联网，无外部字体、图片或 CDN 依赖。
- 推荐使用 Edge / Chrome，并开启硬件加速。
- 单文件版已内联 Three.js，复制这一个 HTML 就可以带走。
- 右上角 `EN / 中` 按钮可一键切换中英文，切换过程中界面会渐隐、模糊并扫过一道光带。

## 接入音乐

| 方式 | 操作 |
| --- | --- |
| 内置音乐 | 点击中央的「选择音频」→「内置音乐 / 朋友的酒 DJ」；或点击「电脑声音」后在来源面板选择 |
| 电脑正在播放的声音 | 网页版：点击「电脑声音」→ 选择 **整个屏幕** → 勾选 **分享系统音频** → 共享。桌面版：点击「电脑声音」后直接选「系统声音」或列表里的某个程序 |
| 本地音乐 | 点击「导入音乐」，或把 MP3 / WAV / M4A / OGG / FLAC 拖进页面 |
| 现场收音 | 点击「麦克风」。麦克风不会外放，只用于驱动画面 |
| 无需音乐 | 点击「演示节拍」，播放内置的 112 BPM A 小调合成节拍 |

音乐只在本机浏览器的 Web Audio 中处理，不会上传到服务器。

### 灵敏度

右下角遥测面板和底部播放器里各有一个 **灵敏度 / SENSITIVITY** 滑块（0.3× — 2.5×）。它控制控制棒对同一段音频的振幅响应：

- 调低：轻微呼吸，适合环境音或作为背景。
- 调高：整片控制棒更猛烈地抬升，适合鼓点强烈的音乐。
- 双击滑块可复位到 1.0×；设置会保存在本机。

### 网页版电脑声音说明

浏览器出于隐私限制，不允许网页静默读取系统音频。页面使用 `getDisplayMedia()` 请求屏幕共享，只读取其中的音频轨道：

1. 点击底部的「电脑声音」。
2. 在浏览器弹窗中选 **「整个屏幕」**，不要只选某个窗口。
3. 打开 **「分享系统音频」** / **「Share system audio」**，再点「共享」。
4. Chrome / Edge 会在地址栏下方显示共享提示；点击「停止捕获」即可停止。

如果弹窗里没有「分享系统音频」选项，通常是浏览器版本或系统不支持（macOS 上的 Chrome 往往不支持）。此时可以使用桌面版、导入音乐，或在系统录音设备中启用「立体声混音」后用「麦克风」采集。

**权限与本地服务器**：浏览器通常只在 `localhost` / HTTPS 下允许麦克风与共享音频。直接双击文件打开时若无法授权，可在本目录运行：

```powershell
python -m http.server 8123
```

然后访问 `http://localhost:8123/index.html`。

## 实现说明

- Three.js r128，全部本地内联，`file://` 直接打开也能运行。
- 976 根控制棒使用 10 组 `InstancedMesh` 渲染，每帧只更新实例矩阵的 Y 轴，保证阵列动画流畅。
- FFT 4096，按 BASS / LOW / MID / HIGH 四个频段计算平滑包络；瞬态检测用来触发鼓点脉冲。
- 频谱直接由堆芯控制棒阵列呈现：由中心向外映射对数频段，中心是低频、外圈是高频；逐棒 FFT 幅度决定升起高度，鼓点会额外推动中心低频棒，阵列形成动态的 3D 频谱壁纸。
- 控制棒高度不再使用 `tanh` 软上限或固定最大高度；每根棒的高度直接响应其所在半径对应的当前频率幅度。
- 每根控制棒额外叠加高频垂直颤动和横向微抖动，鼓点越强抖动越明显；高灵敏下还带有极轻微的堆芯镜头震动，增强“堆芯在抖”的体感。
- 所有控制棒都取消了高度上限。杆体随高度自动向下拉伸，升得再高也仍然连着底座，不会悬空；中心区域响应低频，外圈响应高频。
- 右侧遥测面板新增「播放音量」滑块，桌面端和手机端都能直接调节内置音乐、本地音乐和演示节拍的音量；遥测面板的控制区现在可以正常接收鼠标拖动。
- 内置音乐《朋友的酒 DJ》以 base64 形式直接内嵌在单文件 HTML 中，音乐页不依赖外部路径，复制 HTML 或 EXE 也不会丢歌。
- 内置演示节拍完全由 Web Audio 合成（底鼓、军鼓、踩镲、贝斯、铺底、拨弦与延迟），不依赖音频文件。
- 网页版电脑声音通过 `getDisplayMedia()` 的音频轨道接入；桌面版通过 `loopback-capture` 的 WASAPI loopback 接入。两种方式都不会保存或上传音频。
- 桌面版通过 IPC 把 48 kHz / 16-bit / stereo PCM 送进渲染进程，再用 `AudioBufferSourceNode` 连续调度，保证控制棒响应的连续性。
- 中英文切换采用双阶段界面渐隐、模糊、语言重绘和一条扫光带；所有状态文案、操作说明、音频来源面板都会同步切换。

## 开发与构建

网页版：

```powershell
cd reactor3d
node build.js
```

构建会读取 `src/index.template.html`、`src/style.css`、`vendor/three.min.js` 和 `src/js/*.js`，生成两个内容相同的离线单文件：

- `index.html`
- `控制棒矩阵.html`

桌面 EXE（在 Windows 上需要 Node.js 和 npm）：

```powershell
cd desktop
npm install
npm run dist
node make-launcher.js
```

桌面版使用 Electron + `loopback-capture`（N-API 原生模块）：

- `desktop/dist/CORE07.exe`：便携运行时（可直接在普通 ASCII 路径启动）
- `desktop/release/CORE07.exe`：最终单文件启动器，内嵌了上面的运行时，复制到任意位置即可

自动化验收与截图脚本位于 `test-final.js`、`test-lang.js`、`test-desktop.js` 等，使用 `playwright-core`。它们只用于开发验证，不影响网页运行。
